# Document Summary Assistant

An AI-powered document processing application that accepts PDF and image documents and generates structured summaries.

## Current Status

### Sprint 1 — Document Upload

- PDF upload
- Image upload
- Drag-and-drop support
- File picker support
- File type validation
- 10 MB file size limit
- UUID-based file storage
- FastAPI upload API
- Responsive upload interface
- Basic upload error handling

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS

### Backend

- FastAPI
- Python
